# Стратегия тестирования

## Цель

Проверить основные пользовательские сценарии SauceDemo, негативную обработку данных и согласованность информации между каталогом, корзиной, Checkout и PDF-чеком.

## Объект тестирования

- авторизация;
- каталог и сортировка;
- карточки товаров;
- корзина;
- Checkout: Your Information;
- Checkout: Overview;
- Checkout: Complete;
- генерируемый PDF-чек.

## Подход

- функциональное тестирование основных пользовательских потоков;
- негативное тестирование обязательных полей и форматов;
- проверки переходов между страницами;
- проверки сохранения и очистки состояния корзины;
- проверка арифметики Item total, Tax и Total;
- исследовательские проверки граничных и необычных значений;
- проверка соответствия PDF-чека оформленному заказу.

## Тестовый оракул

Приоритет источников ожидаемого результата:

1. явно наблюдаемое согласованное поведение приложения;
2. зафиксированные исходные ожидаемые результаты;
3. общая практика интернет-магазинов — только как предположение;
4. вопрос владельцу продукта, если требование не подтверждено.

Отсутствие подтверждённого требования не является основанием автоматически ставить Failed.

## Тестовые данные

- `standard_user` / `secret_sauce`;
- `locked_out_user` / `secret_sauce`;
- Sauce Labs Backpack — `$29.99`;
- Sauce Labs Bike Light — `$9.99`;
- заказ из двух товаров: Item total `$39.98`, Tax `$3.20`, Total `$43.18`;
- числовые, отрицательные, пробельные, специальные и длинные строки для негативных проверок.

## Статусы

| Статус | Значение |
|---|---|
| Passed | Проверка выполнена, ожидаемый результат подтверждён |
| Аномалия | Поведение воспроизведено, но дефект зависит от неподтверждённого требования |
| Требует уточнения | Фактический результат известен, тестовый оракул не подтверждён |
| Наблюдение | Факт зафиксирован, но отдельный исторический статус не был назначен |
| Not Run | Нет данных о выполнении |

## Ограничения

- Точные характеристики первоначального окружения не зафиксированы.
- Нет утверждённой спецификации форматов имени и почтового индекса.
- Не проводились проверки API, базы данных, производительности и безопасности.
- Дополнительный контрольный прогон отделён от первоначальных результатов.
