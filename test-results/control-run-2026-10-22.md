# Дополнительный контрольный прогон

Этот прогон выполнен позднее первоначального тестирования и хранится отдельно, чтобы не подменять исходные результаты.

Окружение: Windows 11, Yandex Browser 26.8.5.811.

| Проверка | Результат | Доказательство |
|---|---|---|
| Вход `standard_user` | Passed | Наблюдение в браузере |
| Вход `locked_out_user` | Passed | Отображено сообщение о блокировке |
| Сортировка цены по возрастанию | Passed | `$7.99`, `$9.99`, `$15.99`, `$15.99`, `$29.99`, `$49.99` |
| Добавление и удаление товара | Passed после явной очистки исходной корзины | Наблюдение в браузере |
| Заказ одного Backpack | Passed, Total `$32.39` | [PDF](../evidence/orders/control-run/order-single-item.pdf) |
| Заказ с пустой корзиной | Аномалия повторно воспроизведена, Total `$0.00` | [PDF](../evidence/orders/control-run/order-empty-cart.pdf) |
| Пробельные и неформатные данные | Аномальное поведение повторно воспроизведено | Отдельный файл не создавался |

Номер сборки SauceDemo не отображался приложением.
