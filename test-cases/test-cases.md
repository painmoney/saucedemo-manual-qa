# Тест-кейсы

Тест-кейсы описывают дизайн проверок. Исторические результаты хранятся отдельно и не считаются полным повторным прогоном этих кейсов.

## TC-001 — успешная авторизация

| Поле | Значение |
|---|---|
| Раздел | Авторизация |
| Приоритет | High |
| Тип | Positive, Functional |
| Предусловия | Открыта страница входа; активной сессии нет |
| Тестовые данные | Username: `standard_user`; Password: `secret_sauce` |
| Постусловия | Пользователь авторизован, открыт каталог |
| Связи | CL-001 |

| Шаг | Действие | Ожидаемый результат |
|---:|---|---|
| 1 | Ввести Username | Значение отображается в поле |
| 2 | Ввести Password | Значение скрыто |
| 3 | Нажать Login | Открывается `/inventory.html` |
| 4 | Проверить страницу | Видны каталог из шести товаров и корзина |

## TC-004 — добавление и удаление товаров из корзины

| Поле | Значение |
|---|---|
| Раздел | Каталог и корзина |
| Приоритет | High |
| Тип | Positive, Functional |
| Предусловия | Выполнен вход; корзина пуста |
| Тестовые данные | Sauce Labs Backpack; Sauce Labs Bike Light |
| Постусловия | Корзина снова пуста |
| Связи | CL-020–CL-028 |

| Шаг | Действие | Ожидаемый результат |
|---:|---|---|
| 1 | Добавить Backpack | Кнопка меняется на Remove, счётчик равен `1` |
| 2 | Добавить Bike Light | Счётчик равен `2` |
| 3 | Открыть корзину | Есть две строки: Backpack `$29.99` и Bike Light `$9.99` |
| 4 | Удалить Backpack | Остаётся только Bike Light, счётчик равен `1` |
| 5 | Удалить Bike Light | Корзина пуста, круглый бейдж не отображается |
| 6 | Нажать Continue Shopping | Открывается каталог |
