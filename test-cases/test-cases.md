# Подробные тест-кейсы

## TC-001 — успешный вход

**Приоритет:** высокий  
**Предусловия:** пользователь не авторизован, открыта страница входа.  
**Данные:** `standard_user` и публичный пароль демо-приложения.

| Шаг | Действие | Ожидаемый результат |
|---:|---|---|
| 1 | Ввести имя пользователя | Значение отображается в поле |
| 2 | Ввести пароль | Пароль скрыт |
| 3 | Нажать Login | Открывается Products |
| 4 | Проверить каталог | Видны шесть товаров и корзина |

## TC-002 — заблокированный пользователь не входит

**Приоритет:** высокий  
**Предусловия:** пользователь не авторизован.  
**Данные:** `locked_out_user` и публичный пароль.

| Шаг | Действие | Ожидаемый результат |
|---:|---|---|
| 1 | Ввести данные заблокированного пользователя | Поля заполнены |
| 2 | Нажать Login | Вход отклонён |
| 3 | Проверить сообщение | Указано, что пользователь заблокирован; страница входа остаётся открытой |

## TC-003 — сортировка по возрастанию цены

**Приоритет:** высокий  
**Предусловия:** выполнен вход как `standard_user`, открыт Products.

| Шаг | Действие | Ожидаемый результат |
|---:|---|---|
| 1 | Выбрать `Price (low to high)` | Каталог перестроен |
| 2 | Считать цены сверху вниз | Значения не убывают |
| 3 | Проверить товары с равной ценой | Оба товара присутствуют; внутренний порядок без требования не проверяется |

Ожидаемая последовательность: `$7.99`, `$9.99`, `$15.99`, `$15.99`, `$29.99`, `$49.99`.

**Приоритет:** высокий  
**Предусловия:** выполнен вход, корзина пуста.  
**Данные:** `Sauce Labs Bike Light`.

| Шаг | Действие | Ожидаемый результат |
|---:|---|---|

## TC-005 — успешный заказ одного товара

**Приоритет:** высокий  
**Предусловия:** выполнен вход, корзина пуста.  
**Данные:** `Sauce Labs Backpack`; имя `Test`; фамилия `User`; индекс `00000`.

| Шаг | Действие | Ожидаемый результат |
|---:|---|---|
| 1 | Добавить Backpack и открыть корзину | Один Backpack по цене `$29.99` |
| 2 | Нажать Checkout | Открыта форма данных |
| 3 | Заполнить данные и продолжить | Открыт обзор заказа |
| 4 | Проверить суммы | Товары `$29.99`, налог `$2.40`, итог `$32.39` |
| 5 | Нажать Finish | Появляется `Thank you for your order!` |
| 6 | Создать PDF-чек | Чек содержит товар и те же суммы |

Доказательство: [PDF-чек обычного заказа](../evidence/orders/order-single-item.pdf).

## TC-006 — попытка завершить заказ с пустой корзиной

**Приоритет:** высокий  
**Предусловия:** выполнен вход, в корзине ноль товаров.  
**Данные:** имя `Test`; фамилия `User`; индекс `00000`.

| Шаг | Действие | Предполагаемый ожидаемый результат |
|---:|---|---|
| 1 | Открыть пустую корзину | Товарных строк нет |
| 2 | Проверить Checkout | Кнопка недоступна/скрыта либо следующий шаг отклоняет заказ без товаров |
| 3 | Если переход разрешён, заполнить данные | Завершение недоступно до добавления товара |

**Оговорка:** ожидание основано на обычной практике интернет-магазинов, а не на подтверждённом требовании SauceDemo. Если нулевые заказы разрешены намеренно, поведение штатное.

## TC-007 — валидация формата данных получателя

**Приоритет:** высокий  
**Предусловия:** выполнен вход, в корзине есть товар, открыта форма данных.

| Набор | First Name | Last Name | Zip/Postal Code | Предполагаемый ожидаемый результат |
|---:|---|---|---|---|
| A | один пробел | один пробел | один пробел | Пробелы удалены, показаны ошибки обязательных полей |
| B | `1` | `@` | `ABC` | Имена отклонены, если такие символы запрещены; индекс проверяется по правилам поддерживаемых стран |

**Оговорка:** требования к длине, символам, Unicode и форматам индексов недоступны. Наиболее обоснованная проблема — принятие строк только из пробелов. `ABC` отдельно не считается дефектом, поскольку буквенные индексы существуют.
