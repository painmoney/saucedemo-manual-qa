# ANOM-001 — заказ можно завершить с пустой корзиной

| Поле | Значение |
|---|---|
| Тип | Аномалия продукта / требуется уточнение требований |
| Статус дефекта | Не подтверждён |
| Серьёзность, если поведение непреднамеренное | Major |
| Предлагаемый приоритет | Medium |
| Воспроизводимость | Воспроизведено многократно 22.10.2026 |
| Окружение | SauceDemo; `standard_user`; браузер Yandex (26.8.5.811), Windows 11 |

## Краткое описание

Авторизованный пользователь может начать оформление при нуле товаров, заполнить данные, увидеть обзор на `$0.00`, нажать Finish и получить успешное подтверждение вместе с PDF-чеком.

## Предусловия

1. Выполнен вход как `standard_user`.
2. Корзина пуста.

## Шаги

1. Открыть корзину.
2. Убедиться, что товарных строк нет.
3. Нажать **Checkout**.
4. Ввести `Test`, `User`, `00000`.
5. Нажать **Continue**.
6. Проверить обзор и итог.
7. Нажать **Finish**.

## Фактический результат

- Форма оформления открывается из пустой корзины.
- Обзор показывает стоимость товаров `$0`, налог `$0.00`, итог `$0.00`.
- После Finish появляется `Thank you for your order!`.
- Создаётся PDF-чек без товарных строк с итогом `$0.00`.

## Ожидаемый результат — неподтверждённое предположение

Оформление заказа с нулём товаров обычно блокируется одним из способов:

- Checkout скрыт или недоступен при пустой корзине;
- Continue или Finish требует добавить хотя бы один товар и показывает понятное сообщение.

Это не подтверждённое требование SauceDemo. Если приложение намеренно допускает заказы с нулевой стоимостью, поведение является штатным.

## Возможное влияние

- создание бессодержательных заказов;
- искажение метрик и данных для последующей обработки;
- ложное сообщение об отправке пустого заказа.
