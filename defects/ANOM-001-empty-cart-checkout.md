# ANOM-001 — оформление заказа с пустой корзиной

| Поле | Значение |
|---|---|
| Тип | Аномалия бизнес-логики |
| Статус | Требуется подтверждение требования |
| Предполагаемая Severity | Major, если нулевые заказы запрещены |
| Предлагаемый Priority | Medium |
| Воспроизводимость | Воспроизведено первоначально; повторно подтверждено отдельным контрольным прогоном |
| Окружение первоначального прогона | Windows 11; Yandex Browser 26.8.5.811; версия сборки SauceDemo не отображается |

## Предусловия

1. Выполнен вход как `standard_user`.
2. Корзина не содержит товаров.

## Тестовые данные

- First Name: валидное непустое значение;
- Last Name: валидное непустое значение;
- Zip/Postal Code: валидное непустое значение.

## Шаги

1. Открыть пустую корзину.
2. Нажать **Checkout**.
3. Заполнить все три поля валидными значениями.
4. Нажать **Continue**.
5. Проверить суммы на Overview.
6. Нажать **Finish**.

## Фактический результат

- Checkout доступен при нуле товаров.
- Overview показывает Item total, Tax и Total, равные `$0.00`.
- Finish открывает страницу успешного завершения.
- Пользователь получает сообщение об отправке заказа без товарных позиций.

## Предполагаемый ожидаемый результат

Заказ без товаров нельзя завершить: Checkout, Continue или Finish должен блокировать процесс и сообщать, что корзина пуста.

## Оговорка

Формальное требование не предоставлено. Поэтому запись остаётся аномалией, а не подтверждённым дефектом.

## Риски

- создание бессодержательных заказов;
- искажение статистики и данных последующей обработки;
- ложное подтверждение отправки;
- неочевидная бизнес-логика для пользователя.
