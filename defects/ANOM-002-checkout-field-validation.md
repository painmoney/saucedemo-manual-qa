## Предусловия

1. Выполнен вход как `standard_user`.
2. В корзине есть хотя бы один товар.
3. Открыта `/checkout-step-one.html`.

## Общие шаги

1. Ввести один из наборов данных в форму.
2. Нажать **Continue**.
3. Убедиться, что открылся Overview.
4. Завершить заказ.
5. Сгенерировать PDF.
6. Проверить блок Ship To.

## Предполагаемый ожидаемый результат

- Пробелы по краям удаляются, а фактически пустые обязательные значения отклоняются.
- Максимальная длина ограничена либо длинный текст безопасно переносится без нарушения макета.
- Значения проверяются по документированным правилам поддерживаемых стран и алфавитов.
- При ошибке пользователь получает понятное сообщение рядом с соответствующим полем.

## Оговорки

- Цифры, буквы, дефисы и спецсимволы нельзя объявить недопустимыми без требований и списка поддерживаемых стран.
- Числовой или буквенный индекс может быть корректен в конкретной стране.
- Наиболее сильные подтверждённые проблемы — принятие строк только из пробелов и нарушение макета PDF длинными значениями.

## Риски

- непригодные данные получателя;
- ошибки доставки и поддержки;
- загрязнение данных и аналитики;
- нарушение макета документов;
- возможные проблемы в интеграциях с ограничениями по длине.
